# Prerequisites

Install Ollama on your machine from https://ollama.com/

## How to run the notebooks

**Step 1:** Create a Python virtual environment and install the dependencies from the requirements file.

```bash
python3 -m venv .venv && \
source .venv/bin/activate && \
pip install -r requirements.txt
```

**Step 2:** Run Jupyter Lab, open the link in the browser, and select the notebook you want to run.

```bash
jupyter lab
```
